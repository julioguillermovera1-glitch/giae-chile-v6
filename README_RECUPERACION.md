# Recuperación Estable GIAE Chile v4.0.6

**Creador y Autor Principal:** Julio Vera Concha

Este paquete restaura la versión estable **GIAE Chile v4.0.6 – Inicio Quirúrgico**.

## Configuración recomendada en Cloudflare Pages

Usar:

```txt
Build command: vacío
Build output directory: /
Root directory: /
```

## Importante

- No usar `npm run build`.
- No usar carpeta `public`.
- No reemplazar la estructura por el instalador anterior.
- Mantener `index.html` en la raíz.
- Mantener `css/styles.css`.
- Mantener `js/app.js`.

## Regla de oro

GIAE Chile no debe plagiar código, textos, diseño ni documentación.
Todo debe ser propio o con licencia clara.

## Nota

`index.html` e `indice.html` son iguales en esta versión. Para producción basta con `index.html`.
