# GIAE Chile v2.5.0 - Motor Normativo SEC

Creado por Julio Vera Concha.

## Base
Se parte desde GIAE Chile v2.4.0 Carpeta Técnica Inteligente.

## Regla
No se modifican Proyecto, Cargas, Cuadro, Unilineal, Empalme, Tierra ni Carpeta Técnica.
Se crea la base del Motor Normativo SEC.

## Incluye
- Decreto Supremo N°8.
- RIC 1 al RIC 19.
- Normas IEC referenciales.
- Requisitos de distribuidoras.
- Auditoría normativa preliminar.
- Guardado de auditoría.

## Normativa base
- DS N°8 como reglamento superior.
- RIC 1-19 como pliegos técnicos.
- IEC 60364, IEC 60417, IEC 61439, IEC 60529, IEC 62305 e IEC 60947 como referencias internacionales.
