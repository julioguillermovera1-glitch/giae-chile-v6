# GIAE Chile v2.1.9 - Unilineal Profesional SEC

Creado por Julio Vera Concha.

## Cambios
- Mejora visual completa del Unilineal.
- Diseño más compacto y profesional.
- Respeta suministro:
  - Monofásico: sólo R.
  - Trifásico: R-S-T.
- Barra repartidora:
  - Monofásico: Barra repartidora bipolar 2x100A 10kA.
  - Trifásico: Barra repartidora tetrapolar 4x100A 10kA.
- Símbolo de automático corregido:
  - semicírculo/círculo partido,
  - línea vertical central,
  - alineado al conductor.
- Texto de barra a la derecha, sin montarse en la línea.
- Mantiene SVG, impresión/PDF y generación automática desde cargas/cuadro/empalme.
