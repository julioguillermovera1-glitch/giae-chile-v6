# GIAE Chile v2.3.0 - Tierra Inteligente

Creado por Julio Vera Concha.

## Base estable
Se parte desde GIAE Chile v2.2.0 Empalme Inteligente.

## Regla aplicada
No se modifican Proyecto, Cargas, Cuadro de Carga, Unilineal ni Empalme.
Se agrega únicamente el módulo Tierra.

## Funciones
- Lee Proyecto y Empalme guardado.
- Tierra de Protección TP.
- Tierra de Servicio TS.
- Equipotencialidad.
- Símbolos IEC 60417:
  - TP: IEC 60417-5019.
  - TS: IEC 60417-5018.
  - Equipotencialidad: IEC 60417-5021.
- Tipos de sistemas:
  - Jabalina simple.
  - Jabalinas múltiples.
  - Malla de tierra.
  - Anillo de tierra.
  - Tierra química.
  - Tierra profunda.
  - Sistema existente.
  - Sistema compartido autorizado.
  - Otro sistema especial.
- Resistencia medida.
- Cálculo preliminar de resistencia.
- Validación preliminar RIC 6.
- Informe automático.
- Guardar y continuar a Carpeta Técnica.

## Nota
El cálculo es preliminar. La medición final debe realizarse en terreno con instrumento adecuado.
