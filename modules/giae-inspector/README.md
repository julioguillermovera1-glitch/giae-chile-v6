# GIAE Inspector

Auditor Técnico Inteligente Pre-Presentación.

Este módulo no genera formularios oficiales TE1/TE2/TE3 ni reemplaza la revisión oficial.
Su objetivo es revisar la carpeta técnica, detectar errores, explicar fundamentos y proponer correcciones antes de que el instalador autorizado presente los antecedentes en la plataforma oficial correspondiente.
