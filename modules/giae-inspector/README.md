# GIAE Inspector Técnico

Sistema Inteligente de Auditoría y Validación de Proyectos Eléctricos.

Este módulo no genera formularios oficiales SEC. Su función es revisar la carpeta técnica antes de la presentación, emitir observaciones, proponer acciones de corrección y generar la Certificación Técnica GIAE como respaldo interno.

## Resultado esperado

- Apta para presentación
- Apta con observaciones
- No recomendable presentar

## Advertencia obligatoria

La Certificación Técnica GIAE no reemplaza la revisión, declaración ni aprobación oficial de la autoridad competente.
