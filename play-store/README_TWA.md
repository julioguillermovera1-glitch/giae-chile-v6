# GIAE Chile PWA → Play Store

Esta carpeta deja preparada la versión PWA para envolverla como Android TWA.

Datos sugeridos:
- Package ID: cl.giaechile.app
- Nombre: GIAE Chile
- Start URL: https://TU-DOMINIO/index.html
- Asset Links: /.well-known/assetlinks.json

Pasos pendientes fuera del HTML:
1. Crear cuenta Google Play Console.
2. Generar proyecto TWA con Bubblewrap.
3. Firmar AAB.
4. Copiar huella SHA-256 real en assetlinks.json.
5. Publicar política de privacidad.
6. Subir capturas e ícono 512x512.
