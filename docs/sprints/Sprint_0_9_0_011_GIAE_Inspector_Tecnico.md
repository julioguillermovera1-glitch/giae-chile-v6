# Sprint 0.9.0.011 — GIAE Inspector Técnico

## Objetivo
Integrar el GIAE Inspector Técnico con las reglas RIC 18 y RIC 19 para revisar carpetas técnicas antes de su presentación.

## Incluye
- Motor principal `InspectorEngine`.
- Puente con reglas normativas `InspectorRuleBridge`.
- Cálculo de índice de calidad `InspectorScore`.
- Plan de acción `InspectorActionPlan`.
- Informe técnico `InspectorReport`.

## Política normativa
- GIAE no genera TE1/TE2/TE3 oficiales.
- GIAE revisa antecedentes y carpeta técnica.
- NCh4 no se usa como norma activa de validación.
- La base activa es DS N°8 + RIC vigentes.
