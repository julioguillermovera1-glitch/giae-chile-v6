# Sprint 0.9.0.008 — Motor de Extracción Normativa

## Objetivo
Crear la base del motor que transforma reglas estructuradas NORMA-CHILE en validaciones ejecutables por GIAE.

## Archivos incluidos
- `core/normative-engine/RuleExtractor.js`
- `core/normative-engine/RuleMapper.js`
- `core/normative-engine/RuleResolver.js`
- `core/normative-engine/RuleEvidence.js`
- `core/normative-engine/index.js`
- `data/norma-chile/extractor/extractor-config.json`
- `data/norma-chile/rules/ric-18.seed.json`
- `data/norma-chile/rules/ric-19.seed.json`

## Política normativa
- No copiar textos completos de normas.
- No usar NCh4 para validación activa.
- DS N°8 y RIC vigentes son base normativa principal.
- IEC, ISO y NCh solo se usan cuando son citadas por el marco vigente.
