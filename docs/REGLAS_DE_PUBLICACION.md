# Reglas de publicación – GIAE Chile

1. No publicar si existen archivos duplicados innecesarios.
2. No publicar si existen recursos sin licencia clara.
3. No publicar si `index.html`, `styles.css` o `app.js` no cargan.
4. No publicar si no está incluida la política antiplagio.
5. No publicar si la autoría de Julio Vera Concha no está documentada.
6. No publicar si el sistema rompe la portada de Inicio.
7. No publicar si los módulos principales no están separados de manera ordenada.
