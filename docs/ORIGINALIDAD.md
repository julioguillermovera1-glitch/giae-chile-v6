# Política de originalidad GIAE Chile v1.0

Esta base fue creada desde cero como arquitectura inicial del proyecto.

Reglas del proyecto:

1. No copiar código de páginas web, repositorios ni herramientas de terceros.
2. No copiar textos normativos completos ni material inscrito.
3. Usar fuentes oficiales solo como referencia técnica verificable, redactando reglas propias y citando cuando corresponda.
4. El proyecto antiguo se usará solo como mapa funcional para saber qué módulos existían.
5. Cada módulo nuevo debe tener autoría propia, responsabilidad clara y pruebas independientes.
