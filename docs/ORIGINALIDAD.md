# Política de originalidad GIAE Chile v1.0

Esta base fue creada desde cero como arquitectura inicial del proyecto.

Reglas del proyecto:

1. No copiar código de páginas web, repositorios ni herramientas de terceros.
2. No copiar textos normativos completos ni material inscrito.
3. Usar fuentes oficiales solo como referencia técnica verificable, redactando reglas propias y citando cuando corresponda.
4. El proyecto antiguo se usará solo como mapa funcional para saber qué módulos existían.
5. Cada módulo nuevo debe tener autoría propia, responsabilidad clara y pruebas independientes.

## Autoría e identidad
GIAE Chile v1.0 reconoce como autor intelectual y director del proyecto a Julio Guillermo Vera. La interfaz, documentos y créditos del producto deben reflejar una identidad humana, profesional y sobria, evitando dar la impresión de ser una aplicación genérica generada por IA.

## Marca blanca por empresa
Cada empresa usuaria podrá configurar su propio logo, colores corporativos y plantillas de cotización o trabajo. La personalización visual debe mantenerse sobria: pocos colores, buena legibilidad y estilo técnico.

## Política normativa estricta
La plataforma debe guiar sus opiniones y validaciones únicamente por RIC, IEC y Decreto de Ley N°8 de Chile. Cuando no exista respaldo normativo local suficiente, GIAE debe indicar que requiere revisión normativa y no debe inventar datos.
