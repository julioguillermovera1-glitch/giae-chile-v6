# Etapa 8.0 — Motor de Empalmes RIC 1

Esta etapa incorpora el Motor de Empalmes como componente de ingeniería conectado al Proyecto Activo.

## Incluye

- Selección preliminar monofásica/trifásica.
- Potencias normalizadas iniciales del RIC 1 Anexo 1.3.
- Limitador / interruptor termomagnético sugerido.
- Tipo normalizado referencial A/S/AR/SR según tabla cargada.
- Observaciones técnicas y trazabilidad.
- Datos para Centro de Documentación SEC.
- Materiales base para presupuesto.

## Regla de seguridad

GIAE no inventa potencias normalizadas. Si la potencia no coincide con la tabla cargada o supera el catálogo inicial, el resultado queda como `requiere revisión`.

## Advertencia

El motor prepara antecedentes técnicos. La conexión final depende de la distribuidora, estándares constructivos vigentes, comunicación SEC y revisión profesional competente.
