# Etapa 5.0 · Motor de Tableros Inteligente (RIC 2)

Esta etapa incorpora el primer Motor de Tableros de GIAE Chile v1.0.

## Alcance

- Genera tablero automático desde el Proyecto Activo.
- Usa circuitos del Motor de Ingeniería Eléctrica.
- Propone IGA, DPS, diferenciales, automáticos, barras y gabinete.
- Calcula módulos DIN usados, reserva y gabinete sugerido.
- Genera materiales para presupuesto.
- Deja datos listos para el futuro Motor Unilineal.

## Criterio normativo

El motor queda preparado para RIC 2. Esta versión aplica criterios preliminares y mantiene trazabilidad. Las decisiones definitivas deben ser validadas por instalador autorizado y reglas RIC 2 completadas en el Motor Normativo.

## Principio aplicado

El tablero no se dibuja manualmente: se construye desde cargas, protecciones, conductores y Proyecto Activo.
