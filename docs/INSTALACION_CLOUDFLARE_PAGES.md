# Instalación en Cloudflare Pages – GIAE Chile

**Creador y Autor Principal:** Julio Vera Concha

## Configuración recomendada

- Framework preset: None
- Build command: dejar vacío
- Build output directory: `public`
- Root directory: raíz del repositorio

## Pasos

1. Subir este paquete a GitHub.
2. En Cloudflare Pages, crear proyecto desde el repositorio.
3. Configurar la carpeta de salida como `public`.
4. Publicar.
5. Revisar que carguen:
   - `index.html`
   - `css/styles.css`
   - `js/app.js`
   - `datos/distribuidoras.json`
