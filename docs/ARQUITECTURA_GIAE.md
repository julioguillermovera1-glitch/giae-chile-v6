# ARQUITECTURA GIAE CHILE v1.0

**Creador:** Julio Vera Concha

## Objetivo

Construir un software modular, mantenible y escalable para proyectos
eléctricos bajo normativa chilena.

## Módulos principales

1.  Inicio
2.  Proyecto
3.  Cargas
4.  Motor de Cálculos
5.  Conductores y Protecciones
6.  Cuadro de Carga
7.  Unilineal
8.  Puesta a Tierra
9.  Empalme
10. Validación RIC
11. Documentación
12. Presupuesto
13. Exportación

## Motores internos

-   GIAE Core
-   Motor Eléctrico
-   Motor Normativo
-   Motor Documental
-   Motor Gráfico
-   Motor de Exportación

Cada motor debe ser independiente y reutilizable.
