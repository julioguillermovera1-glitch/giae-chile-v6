# GIAE CHILE -- CARTA FUNDACIONAL DEL PROYECTO

## Versión 1.0

**Proyecto:** GIAE Chile\
**Creador y Autor Principal:** Julio Vera Concha

------------------------------------------------------------------------

# 1. Propósito

Desarrollar un software profesional para el diseño, cálculo, validación
y documentación de instalaciones eléctricas de baja tensión conforme a
la normativa chilena.

------------------------------------------------------------------------

# 2. Visión

Convertir a GIAE Chile en una plataforma nacional de referencia para
instaladores eléctricos, proyectistas, empresas, instituciones
educacionales y organismos relacionados con el sector eléctrico.

------------------------------------------------------------------------

# 3. Misión

Facilitar el desarrollo de proyectos eléctricos mediante herramientas
propias, confiables, auditables y de alta calidad técnica.

------------------------------------------------------------------------

# 4. Principios

1.  Desarrollo 100 % original.
2.  Prohibido el plagio.
3.  Arquitectura modular.
4.  Calidad antes que cantidad.
5.  Cálculos verificables.
6.  Documentación permanente.
7.  Mejora continua.

------------------------------------------------------------------------

# 5. Regla de Oro

**Todo el código, diseño, documentación y lógica del proyecto será
desarrollado específicamente para GIAE Chile o utilizará recursos con
licencias compatibles y debidamente documentadas.**

------------------------------------------------------------------------

# 7. Estándares de desarrollo

-   Código modular.
-   Nombres claros.

-   Registro de cambios obligatorio.
