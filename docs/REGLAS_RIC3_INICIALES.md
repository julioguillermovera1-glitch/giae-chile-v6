# Reglas RIC 3 iniciales - GIAE Chile v1.0

Etapa 3.0.2b.

Este paquete incorpora reglas de ingeniería derivadas del RIC N°03: Alimentadores y demanda de una instalación.

## Contenido inicial

- Definiciones operativas para alimentadores y subalimentadores.
- Demanda, demanda máxima, factor de demanda y factor de simultaneidad.
- Secciones mínimas para alimentadores y subalimentadores.
- Caída de tensión máxima para alimentador y caída total.
- Reglas de shaft vertical para edificios de altura.
- Tabla inicial de factores de demanda de alumbrado.
- Tabla inicial de factores de simultaneidad para conjuntos de viviendas.
- Reglas cruzadas pendientes para RIC 7, RIC 11 y RIC 15.

## Principio aplicado

GIAE no almacena textos completos de la norma. Cada regla es una representación técnica ejecutable o referencial, asociada a un apartado del RIC y a una acción recomendada.
