# Proyecto NORMA-CHILE · Sprint DS8-01

## Objetivo

Digitalizar el Decreto Supremo N°8/2019 como marco legal principal de GIAE, sin copiar el texto completo del decreto dentro del software.

## Archivos agregados

- `data/rules/ds8/rules.json`
- `data/norma-chile/fuentes-normativas.json`
- `data/norma-chile/ds8-articulos-index.json`

## Resultado

Se integraron 32 reglas iniciales DS8, vinculadas con:

- Proyecto Activo / GPE
- Auditoría Integral
- Centro Documental
- Empalmes
- Base de Conocimiento
- Motor Normativo Chile

## Regla de oro

Ningún motor de GIAE debe emitir una decisión técnica sin una referencia normativa registrada en NORMA-CHILE.

## Estructura normativa base

1. DS N°8 como marco legal.
2. RIC 1 al 19 como pliegos técnicos.
3. IEC aplicables como respaldo técnico complementario.
4. Reglas internas GIAE solo para operación del software, nunca para reemplazar normativa.
