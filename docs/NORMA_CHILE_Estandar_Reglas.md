# NORMA-CHILE · Estándar interno de reglas

## ID único
Formato recomendado:

- `CHL-DS8-ART07-001`
- `CHL-RIC04-CON-001`
- `CHL-RIC05-DIF-001`
- `CHL-RIC19-PES-001`

## Campos mínimos

- ID
- Origen
- Documento
- Artículo o apartado
- Categoría
- Condición
- Acción
- Mensaje al usuario
- Nivel
- Estado
- Versión
- Fecha de revisión
- Motores relacionados
- Referencia normativa

## Principio

No copiar textos completos de normas.  
Modelar reglas de ingeniería, referencias y trazabilidad.
