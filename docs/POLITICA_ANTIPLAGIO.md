# POLÍTICA ANTIPLAGIO -- GIAE CHILE

**Proyecto:** GIAE Chile\
**Creador y Autor Principal:** Julio Vera Concha

## Declaración de principios

GIAE Chile es un proyecto de desarrollo propio. Su objetivo es
convertirse en un software profesional para el diseño, cálculo,
validación y documentación de instalaciones eléctricas de baja tensión
conforme a la normativa chilena.

La regla de oro del proyecto es:

> **No se plagia absolutamente nada.**

Todo desarrollo deberá ser original o utilizar recursos con licencia
compatible y debidamente documentados.

## Normas obligatorias

1.  Todo el código fuente será desarrollado específicamente para GIAE.
2.  No se copiará código desde programas comerciales o proyectos de
    terceros.
3.  La interfaz gráfica será de diseño propio.
4.  Los textos técnicos serán redactados por el equipo del proyecto y no
    copiados de manuales o normas.
5.  Las normas RIC, SEC y demás reglamentos solo serán utilizadas como
    referencia técnica. No se reproducirán textos protegidos por
    derechos de autor cuando corresponda.
6.  Toda información externa utilizada deberá quedar registrada en la
    documentación del proyecto.
7.  Cada módulo nuevo deberá indicar autor, fecha y propósito.

## Compromiso

Esta política es obligatoria para todas las versiones presentes y
futuras de GIAE Chile.
