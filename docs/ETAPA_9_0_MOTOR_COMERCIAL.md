# Etapa 9.0 — Motor Comercial / Presupuestos Inteligentes

Esta etapa agrega el Motor Comercial GIAE como componente conectado al Proyecto Activo.

## Alcance

- Calcula presupuesto preliminar desde materiales técnicos generados por los motores.
- Integra materiales de Ingeniería, Tableros, Empalme, Tierra y Documentación.
- Permite mano de obra, IVA, margen y descuento configurables.
- Genera reporte JSON descargable.
- Mantiene la regla: los precios deben ser configurados por la empresa o instalador. GIAE no inventa precios comerciales.

## Fuente de datos

El motor comercial lee desde:

- Proyecto Activo.
- BUCE.
- Motor de Ingeniería.
- Motor de Tableros.
- Motor de Empalmes.
- Centro Documental.

## Estado

Versión inicial funcional para v1.0.
